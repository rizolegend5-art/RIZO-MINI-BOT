## 🛠️ Manual Installation Guide

For users who prefer total control, follow these steps to run the bot locally or on a VPS (Termux compatible).

### 1. Prerequisites
Ensure you have the following installed:
*   **Node.js** (v14 or higher)
*   **Git**
*   **FFmpeg** (Required for media processing)

### 2. Steps
```bash
# 1. Clone the repository
$ git clone [https://github.com/rizo/rizo-mini-bot.git](https://github.com/rizo/rizo-mini-bot.git)
$ cd rizo-mini-bot

# 2. Install dependencies
$ npm install

# 3. Configure the bot
# Rename config.example.js to config.js and edit with your credentials.
$ cp config.example.js config.js

# 4. Start the bot
$ npm start
